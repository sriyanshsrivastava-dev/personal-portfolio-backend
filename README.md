# 🚀 Portfolio Backend API

A robust and scalable backend service powering my personal portfolio website.  
Built using **Java 17** and **Spring Boot**, this project is designed with clean architecture, best practices, and production-ready patterns in mind.

---

## 📌 Overview

This backend handles all core functionalities of the portfolio platform, including:

- Managing projects and experience data  
- Serving dynamic content via REST APIs  
- Handling contact form submissions  
- Providing a structured and extensible backend system  

The goal is to build a **clean, maintainable, and scalable backend** that reflects real-world development standards.

---

## 🛠️ Tech Stack

- Java 17  
- Spring Boot 4.0.5  
- Spring Web  
- Spring Data JPA  
- Hibernate  
- RESTful API Design  
- Maven (Build Tool)  

---

## ⚙️ Getting Started

### Prerequisites

- Java 17+  
- Maven 3+  
- IDE (IntelliJ / VS Code / Eclipse)  

---

### 🔧 Installation & Run

```bash
# Clone the repository
git clone https://github.com/sriyanshsrivastava-dev/personal-portfolio-backend.git

# Navigate to project folder
cd personal-portfolio-backend

# Build the project
mvn clean install

# Run the application
mvn spring-boot:run
````
